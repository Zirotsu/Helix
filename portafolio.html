Desafío

El cliente requería una plataforma SaaS multi-tenant capaz de orquestar múltiples agentes IA sobre una capa común, con autenticación, aislamiento de datos por cliente, y un panel para gestionar la operación completa. El objetivo final: licenciar la plataforma a otras empresas como producto comercial con un catálogo de agentes verticales.

Solución entregada

Plataforma SaaS completa con orquestador central, agentes modulares de Ventas y Analítica, onboarding guiado, sistema de roles, dashboard de KPIs y edge functions para procesamiento IA. El producto quedó vendiendo a empresas en Chile y Estados Unidos en sus primeras semanas, con MRR activo.

Omni Manager · Plataforma modular
Desafío

Muchas pymes todavía operan con planillas, cuadernos y aplicaciones separadas para ventas, inventario, clientes, caja y reportes. El desafío de Omni Manager fue unificar esa operación en una plataforma flexible, capaz de adaptarse a distintos rubros y crecer por módulos sin obligar al negocio a usar herramientas innecesarias.

Solución entregada

Omni Manager centraliza punto de venta, inventario persistente en la nube, caja, compras, promociones, reportes, códigos de barras y un asesor de negocio con IA. Su arquitectura modular ofrece configuraciones para minimarkets, botillerías, talleres mecánicos, veterinarias, panaderías, pastelerías y restaurantes, con acceso desde distintos equipos y soporte multi-local. Botillería El Bolón es una de sus implementaciones reales en producción.
