by HelixFix
En producción · Chile + USA
Sector
SaaS B2B · PYME
Tipo
Plataforma multi-agente IA
Entrega
2026
Modelo
Licencia + MRR
Dashboard general
Desafío

El cliente requería una plataforma SaaS multi-tenant capaz de orquestar múltiples agentes IA sobre una capa común, con autenticación, aislamiento de datos por cliente, y un panel para gestionar la operación completa. El objetivo final: licenciar la plataforma a otras empresas como producto comercial con un catálogo de agentes verticales.

Solución entregada

Plataforma SaaS completa con orquestador central, agentes modulares de Ventas y Analítica, onboarding guiado, sistema de roles, dashboard de KPIs y edge functions para procesamiento IA. El producto quedó vendiendo a empresas en Chile y Estados Unidos en sus primeras semanas, con MRR activo.

React 19 TypeScript Supabase Edge Functions OpenAI Tailwind Multi-tenant RLS

PymeManager

Retail · Almacén / Botillería
Tipo
POS + Inventario + IA
Cliente
Botillería El Bolón · Maipú
Plataforma
Escritorio + Nube
Dashboard · Inicio Almacén
Desafío

Un almacén / botillería de barrio necesitaba dejar atrás el cuaderno y la planilla: controlar ventas, boletas, inventario crítico y caja en una sola herramienta simple, que funcionara incluso sin depender de internet y mantuviera los datos del negocio bajo su control.

Solución entregada

Plataforma de gestión con punto de venta, control de inventario con stock crítico, promociones, reportes con IVA y un asesor comercial con IA que responde sobre los datos reales del negocio. Entregada para la operación real de Botillería El Bolón, con su catálogo, ventas y métricas en vivo.

03 · Caso
TallerManager
Producción · Chile + Perú
Sector
Talleres automotrices
Tipo
Vertical SaaS · OT + Stock
Mercado
Chile + Perú (SUNAT)
Modelo
Licencia + nube multi-tenant
Dashboard · Inicio Taller
Desafío

Los talleres mecánicos llevaban sus órdenes de trabajo en papel: vehículos, diagnósticos, mano de obra, repuestos y pagos dispersos, sin trazabilidad ni control de stock. Se necesitaba un sistema vertical que ordenara el ciclo completo de reparación y se adaptara a la normativa de cada país.

Solución entregada

SaaS vertical para talleres: órdenes de trabajo con ficha de vehículo, mecánico asignado, repuestos e inventario, gastos, reportes y asesor mecánico con IA. Arquitectura multi-tenant en la nube con licencias por cliente y soporte para Chile y facturación electrónica SUNAT en Perú.

React 19 TanStack Start TypeScript Supabase Gemini AI Multi-tenant SUNAT / IGV RLS
